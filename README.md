# Mitigating Physical Incoherence in Data-Driven Piano Synthesis via Mechano-Acoustic Constraints

[![PyTorch](https://img.shields.io/badge/PyTorch-2.0+-ee4c2c.svg)](https://pytorch.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

This repository contains the official PyTorch implementation and dataset for the ISMIR 2026 paper: **"Mitigating Physical Incoherence in Data-Driven Piano Synthesis via Mechano-Acoustic Constraints"**. 

The piano sustain pedal operates as a coupled mechano-acoustic system. While recent data-driven models achieve impressive audio synthesis, end-to-end black-box architectures systematically bypass this sequential physical transmission chain, resulting in severe **physical incoherence** (manifesting as a cascading artifact of high-frequency mechanical jitter driving an unnatural acoustic decay). 

To resolve this, we propose **NPPS (Neural Piano Physical Synthesis)**, a hybrid framework that injects a unified mechano-acoustic bottleneck into the generation pipeline, thoroughly eliminating digital artifacts without compromising end-to-end data fidelity.

![System Architecture](NPPS_Architecture_Ready.png) 

## ✨ Key Features
- **Neural Perception Frontend**: Blindly extracts latent pedal probabilities from unpedaled "dry audio" using a U-Net backbone.
- **Mechanical Kinematic Constraint**: Introduces the Local Context-Aware Schmitt Trigger (LCAST) and asymmetric physical inertia. This layer enforces strict kinematic boundaries on the predicted intent, driving the **Directional Inversion Rate (DIR)** down to 0.00 Hz and eradicating digital stuttering.
- **Acoustic Resonance Constraint**: Employs a Dual-Stage Decay engine and an anti-aliasing harmonic exciter driven directly by the validated mechanical state. It accurately reconstructs the energy dissipation and "spectral bloom" (yielding a **+11.12 dB** high-frequency gain).

## 📊 Experimental Results

Evaluated in a completely blind manner on the MAESTRO v3.0.0 dataset, our system explicitly proves a "divide and conquer" regularization mechanism. The expanded ablation matrix demonstrates how mechanical constraints govern kinematics (TV, DIR) while acoustic constraints govern spectra (Peak HF Gain, FAD).

| Method | LCAST & Inertia | Dual-Stage Exciter | TV (↓) | DIR (Hz, ↓) | Peak HF Gain (↑) | RMS Corr (↑) | FAD (↓) |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: | :---: |
| FluidSynth Wet (*) | - | - | - | - | - | **0.2274** | 11.0834 |
| Ablation: w/o LCAST | ✖ | ✔ | 12.80 | 74.62 | +10.85 dB | 0.0143 | 9.8843 |
| Ablation: w/o Dual-Stage| ✔ | ✖ | **0.90** | **0.00** | +0.65 dB | 0.0062 | 10.0246 |
| **Proposed (Full NPPS)** | ✔ | ✔ | **0.90** | **0.00** | **+11.12 dB** | 0.0136 | **9.8853** |

*\* FluidSynth acts as a privileged baseline consuming perfect Ground Truth MIDI timing.*

## 🚀 Usage

### 1. Inference and Audio Generation
To use the pre-trained NPPS model to generate physically coherent wet audio from a given dry audio file:

```bash
python generate.py --config configs/default.yaml --input data/maestro_dry/sample.wav --output results/sample_wet.wav
```

### 2. Training from Scratch
To train the U-Net perception module from scratch using the BCE loss against MIDI CC64 trajectories:

```bash
python train.py --config configs/default.yaml
```

### 3. Mechanistic & Macroscopic Evaluation
Run the unified evaluation script to generate the Orthogonal Metrics Matrix (TV, DIR, Peak HF Gain, FAD) and reproduce the visual plots (Kinematic Trajectories & Spectral Bloom):

```bash
python evaluate.py --checkpoint checkpoints/best_pedal_net.pth
```
The generated figures will be saved in the `results/figs/` directory by default.
